COMO GERAR O APK:
─────────────────

MÉTODO RÁPIDO (Android Studio):
  1. Instale o Android Studio: https://developer.android.com/studio
  2. Abra o Android Studio
  3. Clique em "Open" e selecione a pasta "android/" deste projeto
  4. Aguarde o Gradle sincronizar (pode demorar na primeira vez)
  5. Clique em Build → Build Bundle(s) / APK(s) → Build APK(s)
  6. O APK estará em: android/app/build/outputs/apk/debug/

MÉTODO LINHA DE COMANDO:
  1. Configure o SDK: copie local.properties.template → local.properties
     e coloque o caminho do seu Android SDK
  2. Execute: ./build_apk.sh
  3. Para APK de release (Play Store), veja abaixo ↓

APK DE RELEASE (para publicar):
  1. Execute: ./gerar_keystore.sh  (uma vez só, guarde o arquivo!)
  2. No Android Studio: Build → Generate Signed Bundle/APK
  3. Escolha APK, selecione a keystore e siga os passos

ESTRUTURA:
  www/index.html        ← O jogo HTML (já configurado)
  android/              ← Projeto Android completo
  capacitor.config.ts   ← Configurações do Capacitor
  build_apk.sh          ← Script de build rápido

REQUISITOS:
  - Java JDK 17+
  - Android Studio (com SDK Android 22+)
  - Node.js 18+
